Manage access

Only the owner grants or revokes, and peers enforce it on every write. Levels nest: write adds editing to read, and delete adds removal on top. New documents grant the superadmin delete so someone can moderate — moderation is granted here, not inherited from a role, and you can revoke it.

read is an intent label, not confidentiality: in a P2P graph every peer already holds the bytes. Encrypt the value to keep it private.
